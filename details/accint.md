## Overview
AccInt is a local-first MCP Work Model for coding agents. It retrieves scored memory, records commitments and actions with receipts, and credits results after real outcomes such as tests, owner approval, or replies.

## Features

- Local MCP server and CLI for Claude Code, Codex, OpenCode, and Cursor
- Two MCP tools: `acc_retrieve` and `acc_act`
- Local `acc.db` Work Model; no cloud memory account or API key required
- Official MCP Registry entry: `io.github.maxbaluev/accint`

## Source boundary

Public Apache-2.0 installer, docs, plugins, and registry metadata; proprietary local engine binary with private engine source.
