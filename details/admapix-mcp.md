# AdMapix MCP

AdMapix MCP exposes raw advertising creative data to MCP-compatible agents.
It is useful for competitor research, creative discovery, and ad intelligence
workflows.

## Links

- [Website](https://www.admapix.com/)
- [Source repository](https://github.com/fly0pants/admapix)

## Capabilities

The `search_creatives` tool supports searches by keyword, app, advertiser, or
ad copy, with filters for creative type, country or region, date range, and
industry category. Results are returned as structured JSON records from the
AdMapix API.

## Setup

The public repository includes install scripts for macOS, Linux, and Windows.
An AdMapix API key is required.
