# AdMapix MCP

MCP server for searching ad creative data by keyword, advertiser, app, country, date range and creative type, for competitor and creative research.

## Basic Info

- **Name:** AdMapix MCP
- **Category:** Marketing
- **Source URL:** https://www.admapix.com/
- **Source Repository:** https://github.com/fly0pants/admapix
- **PyPI:** https://pypi.org/project/admapix-mcp/
- **Tags:** `advertising`, `marketing`, `research`, `python`

## Features

- `search_creatives`: search ad creatives by keyword, app name, advertiser, category or ad copy.
- Filter by creative type, country or region, date range and industry.
- Sort by first seen, relevance, estimated impressions or days active.
- Returns structured JSON records with media URLs and metrics.

## Setup

- Install with `pip install admapix-mcp` (the repository also has install scripts for macOS, Linux and Windows).
- Set the `ADMAPIX_API_KEY` environment variable before starting the server.
