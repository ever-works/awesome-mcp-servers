# Agent Cards

MCP server for AgentCard: AI agents create and spend prepaid virtual Visa cards with fixed budgets and handle 402 Payment Required responses.

## Basic Info

- **Name:** Agent Cards
- **Category:** Finance & Fintech
- **Source URL:** https://github.com/tiny-agent-company/mcp
- **MCP Endpoint:** `https://mcp.agentcard.sh/mcp`
- **Website:** https://agentcard.sh
- **Tags:** `payments`, `ai-agents`, `fintech`

## Features

- Agents create prepaid virtual Visa cards, each with a fixed budget.
- Make payments and check balances.
- Handle 402 Payment Required responses automatically.

## Setup

- `npx agent-cards signup` creates an account; `npx agent-cards setup-mcp` configures Claude Code.
- Remote endpoint for other clients: `https://mcp.agentcard.sh/mcp`
