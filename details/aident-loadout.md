## Overview

Aident Loadout is a remote MCP server and Agent Skill that connects coding agents and chat clients to 1,000+ apps through one reusable setup.

## Features

- Tools for 1,000+ apps through a single remote MCP endpoint
- 400+ expert-built Skills for research, outreach, content, and operations
- OAuth in the browser; API keys stay in Aident Vault
- Cost preflight and Audit log for every action
- Works with Codex, Claude Code, Cursor, ChatGPT, Claude Desktop, and other MCP clients

## Use Cases

- Cross-service agent workflows (Gmail, Slack, GitHub, Linear, Notion, and more)
- One Loadout shared across multiple AI agents instead of per-app MCP installs
