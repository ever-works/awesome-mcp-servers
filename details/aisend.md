# AISend

Transactional email API that AI agents operate and you supervise: send from your verified domain, check delivery and validate addresses over MCP, or use a Resend-compatible REST API.

## Basic Info

- **Name:** AISend
- **Category:** Messaging MCP Servers
- **Source URL:** https://aisend.app
- **MCP Endpoint:** `https://api.aisend.app/mcp`
- **Tags:** `email`, `transactional-email`, `remote`, `oauth`

## Features

- Hosted remote MCP endpoint `https://api.aisend.app/mcp`; OAuth or API key (you approve the connection and can revoke the key).
- Registry name `app.aisend/aisend`; npm package `aisend-mcp` 0.3.0.
- Free plan, no card: 10 sandbox test emails to your own verified address. Sending to your own recipients needs a verified domain and a paid plan (Pro from $14/month).
- Disclosure: submitted by the AISend team.

## Setup

- Add `https://api.aisend.app/mcp` as a remote MCP server and sign in; see https://aisend.app.
