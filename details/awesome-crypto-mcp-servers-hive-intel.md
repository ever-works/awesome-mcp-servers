# Awesome Crypto MCP Servers by Hive Intelligence

Maintained curated list of high-quality Model Context Protocol servers for crypto, Web3, DeFi, wallets, trading, on-chain data, Blockchain development, and AI agents.

## Overview

This list helps developers and AI agents choose the right crypto MCP server by task instead of browsing a raw catalog. It prioritizes maintained projects with clear MCP interfaces, useful coverage, safe setup paths, and explicit handling of credentials, signing, trading, or write-operation risk.

## Key Features

- Quick routes for common crypto MCP jobs
- Best-by-use-case map for comparing broad and provider-specific servers
- Curated categories for market data, DeFi, wallets, Solana, Bitcoin, layer-1 chains, security, social signals, NFTs, and prediction markets
- Risk routing for wallet, signing, trading, custody, infrastructure-admin, and write-capable tools
- AI-readable `llms.txt` index for agents and directory crawlers
- Contribution rules for accepting, rejecting, and removing entries

## Use Cases

- Choose a broad crypto intelligence MCP for an AI agent
- Compare provider-specific market-data, wallet, DeFi, DEX, NFT, Solana, or security MCPs
- Find safer read-only MCPs before escalating to signing, trading, or custody tools
- Audit crypto MCP options by maintenance, setup path, provenance, and risk posture
- Discover related MCP directories and registries for further research
