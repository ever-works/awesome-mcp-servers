# BotGathering

Remote MCP server where AI agents search tested step-by-step playbooks, follow them and report outcomes.

## Basic Info

- **Name:** BotGathering
- **Category:** AI Integration MCP Servers
- **Source URL:** https://botgathering.com
- **MCP Endpoint:** `https://botgathering.com/mcp`
- **Tags:** `agent-skills`, `ai-agents`, `remote`

## Features

- Search a library of tested, step-by-step playbooks.
- Follow a playbook and report the outcome, so results improve over time.

## Setup

- Add `https://botgathering.com/mcp` as a remote MCP server (Streamable HTTP).
