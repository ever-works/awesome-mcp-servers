# CardDeals MCP Server

Search and compare real-time U.S. digital gift card discounts and deal-stacking tips across 700+ brands; anonymous, free and read-only.

## Basic Info

- **Name:** CardDeals MCP Server
- **Category:** Business Commerce MCP Servers
- **Source URL:** https://github.com/cello305/carddeals-mcp
- **MCP Endpoint:** `https://catalog.carddeals.co/mcp`
- **Website:** https://carddeals.co/mcp
- **Tags:** `gift-cards`, `shopping`, `e-commerce`, `remote`

## Features

- Search discounted digital gift cards across 700+ retail, dining, travel and entertainment brands.
- Compare discounts across sellers and find deal-stacking tips.
- Anonymous, free and read-only.

## Setup

- Add `https://catalog.carddeals.co/mcp` as a remote MCP server (Streamable HTTP) in Claude Desktop, Cursor or any MCP client.
