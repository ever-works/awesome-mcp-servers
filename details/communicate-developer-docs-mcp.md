## Overview

Communicate Developer Docs MCP is an official public, read-only Streamable HTTP server for developer documentation and API discovery.

Endpoint: `https://communicate.so/mcp`

Documentation: https://communicate.so/developers

Server card: https://communicate.so/mcp/server-card

## Features

- `communicate_get_developer_guide`: canonical developer guide, API URLs, authentication boundaries and support contact.
- `communicate_get_openapi_summary`: published REST API operations and canonical OpenAPI URL, without calling the authenticated API.
- `communicate_get_support_contact`: official support email, contact page and inquiry categories, without sending messages.
- No account or API key required; no workspace/customer data access or product actions.

## Pricing

The public documentation MCP is free. Authenticated Communicate workspace features are a separate service and are not exposed by this endpoint.
