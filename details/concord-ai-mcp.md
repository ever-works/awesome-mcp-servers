# Concord AI MCP

Local-first shared work state for coding agents: presence, claims, messaging, handoffs and review packets so several agents can work in one repository without colliding.

## Basic Info

- **Name:** Concord AI MCP
- **Category:** AI Agents & Orchestration MCP Servers
- **Source URL:** https://github.com/Get-Concord-AI/concord-mcp
- **Website:** https://getconcord.ai
- **Tags:** `coding-agent`, `collaboration`, `typescript`, `stdio`

## Features

- Presence: see which agents are active in a repository.
- Claims: agents claim files or tasks before working on them.
- Messaging and handoffs between agents.
- Review packets for handing finished work to a reviewer.

## Setup

- Run locally over stdio: `npx -y @concord-ai/concord-mcp`
