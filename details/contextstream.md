# ContextStream

ContextStream is a hosted MCP server for shared project context across Cursor, Claude Code, Codex, Grok, and other MCP clients. Official registry: `io.contextstream/mcp`.

## Features

- Shared project context that stays available across tools and sessions
- Hosted MCP endpoint for quick connect (`https://mcp.contextstream.io/mcp`)
- Official MCP registry entry: `io.contextstream/mcp`
- Open-source MCP server and public benchmarks for with-vs-without context

## Connection

- **Website:** https://contextstream.io
- **Hosted MCP:** https://mcp.contextstream.io/mcp
- **Registry:** `io.contextstream/mcp`
- **OSS MCP server:** https://github.com/contextstream/mcp-server
- **Benchmarks:** https://contextstream.io/benchmarks
