## Overview

Continuity is a private story bible for fiction writers that connects to ChatGPT, Claude, Gemini, Grok, Cursor, and other MCP clients. It keeps characters, relationships, world rules, timelines, and approved scenes as locked canon so AI drafting stays consistent.

## Key Features

- Hosted Streamable HTTP MCP at `https://continuitywriter.com/mcp`
- OAuth 2.1 authentication
- Manage story projects and search continuity context
- Update locked canon (characters, relationships, world rules, timelines)
- Record approved scenes and save checkpoints
- Run continuity checks before the next draft
