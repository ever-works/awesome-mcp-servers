# CVPosh

Resume and CV builder with an ATS-style checker. Its read-only MCP server lets an AI assistant read your saved CVs, score them for ATS compatibility and compare them with a job posting.

## Basic Info

- **Name:** CVPosh
- **Category:** Business Productivity
- **Source URL:** https://cvposh.com
- **MCP Endpoint:** `https://cvposh.com/api/mcp`
- **Tags:** `resume-builder`, `job-matching`, `career`, `remote`, `oauth`

## Features

- Hosted remote MCP endpoint `https://cvposh.com/api/mcp`; OAuth. Read-only: an agent cannot create, edit, delete, export or share a CV.
- Registry name `com.cvposh/cvposh`.
- Free plan: full editor, an ATS check, 1 PDF export and 1 AI job-tailoring run; a free account gets 100 tool calls a day per connection. Pro is $9 once (lifetime) or $5/month.
- Disclosure: submitted by the CVPosh team.

## Setup

- Add `https://cvposh.com/api/mcp` as a remote MCP server and sign in; see https://cvposh.com.
