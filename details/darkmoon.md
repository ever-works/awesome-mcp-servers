# Darkmoon

Open-source (GPLv3) autonomous penetration testing platform that runs 80+ offensive security tools through 50 specialist agents behind a controlled MCP layer, with a fully local mode.

## Basic Info

- **Name:** Darkmoon
- **Category:** Security Attestation Mcp Servers
- **Source URL:** https://github.com/ASCIT31/Dark-Moon
- **Tags:** `security`, `vulnerability-scanning`, `open-source`

## Features

- Autonomous penetration testing of targets you are authorized to test: the agent reasons, plans and runs the assessment.
- 50 specialist agents across web, API, cloud, Active Directory, Kubernetes, CI/CD and AI/LLM (OWASP LLM Top 10).
- Every action goes through a controlled, logged MCP interface to a Docker toolbox of offensive security tools.
- Proof of exploitation on every finding.
- Fully local mode with a local LLM behind a privacy gateway.
