## Overview

Persistent cross-session memory MCP server for AI coding tools.

## Features

- SQLite-backed state storage that survives context resets
- Works with 13+ AI coding tools (Claude Code, Cursor, Gemini CLI, Codex, Windsurf, Kiro, etc.)
- Stores project decisions, preferences, and next steps
- MCP-native integration with all supporting tools

## Use Cases

- Keep agent context alive across sessions
- Share project state between multiple AI coding tools
- Never lose decisions or context after a context window reset

## Comparisons

Local-first persistent memory vs cloud-based alternatives; zero external dependencies.
