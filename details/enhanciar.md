# Enhanciar

Enhanciar is a company brain. It connects to the tools a team already uses and answers questions in plain English, with a link to where each answer came from. Its hosted MCP server lets Claude, Cursor and other MCP clients ask it questions directly.

## Connection

- Hosted endpoint: `https://enhanciar.in/enhanciar/mcp/`
- Transport: Streamable HTTP
- Authentication: an Enhanciar API key, sent as a Bearer header
- Setup documentation: https://enhanciar.in/mcp
- MCP Registry: in.enhanciar/enhanciar

## What it can do

- Answer questions from Slack, Gmail, Google Drive, Notion, Jira, Linear, GitHub, Zendesk and Postgres, with a source link on each claim
- Search the team's connected sources
- Respect permissions: people only see what they already have access to

Paid plans; users bring their own AI key (Gemini, OpenAI or Anthropic). The hosted service is proprietary.
