# ERIUS PHONE MCP

MIT-licensed Python MCP server that gives AI agents persistent cloud Android devices: UI trees, screenshots, touch input, app management and crash logs.

## Basic Info

- **Name:** ERIUS PHONE MCP
- **Category:** OS Automation
- **Source URL:** https://github.com/Protremix/erius-phone-mcp
- **Website:** https://eriusphone.com
- **Tags:** `android`, `mobile`, `python`, `stdio`

## Features

- Read the device UI tree and take screenshots.
- Tap, swipe and type on a real Android phone.
- Install, launch and manage apps.
- Read crash logs.

## Setup

- Install with `uvx erius-phone-mcp` or `pip install erius-phone-mcp`.
- The ERIUS PHONE cloud device service is in early access, by invitation.
