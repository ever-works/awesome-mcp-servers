# FalcoScan

Remote MCP server for AI market intelligence. Agents can look up AI products by market, compare competitors, and check which products have shut down or been acquired, across a catalog of 8,000+ AI tools in 30 markets.

## Basic Info

- **Name:** FalcoScan
- **Website:** https://falcoscan.com
- **MCP Endpoint:** `https://falcoscan.com/api/mcp` (Streamable HTTP)
- Also listed in the official MCP Registry, Smithery and Glama.

## Features

- Find AI tools within a market and compare competitors.
- Track AI products that have shut down or been acquired.
- Market-level view of where demand is growing.

## Setup & Configuration

- Get an API key at https://falcoscan.com.
- Add `https://falcoscan.com/api/mcp` as a remote MCP server and pass the API key as the client's configuration asks.
