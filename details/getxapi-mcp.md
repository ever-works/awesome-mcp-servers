# GetXAPI MCP

Official GetXAPI MCP server for X/Twitter data: search tweets, read profiles and followers, and fetch tweets over Streamable HTTP with Bearer token auth.

## Basic Info

- **Name:** GetXAPI MCP
- **Category:** Social
- **Brand:** GetXAPI
- **Source URL:** https://github.com/getxapi/getxapi-mcp
- **Website:** https://www.getxapi.com
- **Tags:** `twitter`, `social-media`, `api`

## Features

- `search_tweets`, `get_user_profile`, `get_user_followers` and `get_tweet_by_id` tools.
- Streamable HTTP transport with Bearer token authentication.

## Setup

- Published on npm as `@getxapi/mcp`.
