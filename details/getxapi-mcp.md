# GetXAPI MCP

MCP server for X/Twitter data access. Exposes `search_tweets`, `get_user_profile`, `get_user_followers`, and `get_tweet_by_id` tools over a Streamable HTTP transport with Bearer token authentication. Published on npm as `@getxapi/mcp`, MIT licensed.

[https://github.com/getxapi/getxapi-mcp](https://github.com/getxapi/getxapi-mcp)
