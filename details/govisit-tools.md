# GoVisit Tools

GoVisit Tools is a hosted MCP server for read-only access to GoVisit's published travel information. Its tools support searching places and destinations and reading published place, destination, collection, category, blog, and documentation content.

- **Endpoint:** `https://govisit.ai/mcp`
- **Transport:** Streamable HTTP
- **Authentication:** Public reads do not require a GoVisit API key
- **Connection guide:** [GoVisit MCP documentation](https://govisit.ai/en/docs/developers/mcp/overview)
- **Agent Skills:** [GoVisit Toolkit](https://github.com/inhotel-io/govisit-toolkit) provides companion portable skills and integration resources; it is not the hosted server implementation.

The server returns GoVisit's published content. Use it under the [GoVisit Data Use License](https://govisit.ai/en/docs/legal/data-use-license).
