# Hive Intelligence MCP Server

## Overview

Hive Intelligence is a managed crypto intelligence MCP for AI agents. The canonical public repository is `hive-intel/hive-sdk`, which documents hosted MCP access, local stdio setup through the `hive-intelligence` npm package, a TypeScript SDK, and installable agent skills.

## Features

- Hosted MCP endpoint for agent-facing crypto intelligence
- Local stdio support through the `hive-intelligence` npm package
- TypeScript SDK for developer integrations
- Workflow-oriented agent skills for common crypto research tasks
- Coverage across market data, DeFi, wallets, security, DEX flows, NFTs, Solana, infrastructure, and prediction markets
- Schema-first tool discovery and bounded execution paths for agents

## Use Cases

### Market Research

Route an agent to crypto market data, token metadata, prices, categories, and provider-specific market intelligence without wiring each provider separately.

### Token Diligence

Investigate token contracts, holder activity, security signals, DEX pools, liquidity, and provenance before summarizing risk to a user.

### Wallet Investigation

Analyze wallet holdings, transaction patterns, portfolio context, and DeFi exposure with provider provenance and runtime status surfaced to the agent.

### DeFi And DEX Research

Inspect DeFi protocols, pools, swaps, liquidity, TVL, yield, and DEX flow signals through task-oriented workflows rather than raw endpoint browsing.

### Agent Integration

Use the hosted MCP server for remote clients, local stdio for desktop clients and self-hosted experiments, the SDK for application code, and skills for agent routing.

## Integration

- Repository: https://github.com/hive-intel/hive-sdk
- Hosted MCP: `https://mcp.hiveintelligence.xyz/mcp`
- Local package: `hive-intelligence`
- Canonical local command: `npx -y -p hive-intelligence@latest hive`
