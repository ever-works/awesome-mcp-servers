# Ignav Flights

Hosted MCP server with live flight prices, booking links and airport lookup for AI agents and travel apps.

## Basic Info

- **Name:** Ignav Flights
- **Category:** Travel Transportation
- **Source URL:** https://ignav.com/docs/mcp
- **MCP Endpoint:** `https://ignav.com/mcp`
- **Agent Skill:** https://github.com/gusgordon/ignav-skill
- **Tags:** `flights`, `travel`, `remote`

## Features

- Live flight prices.
- Booking links.
- Airport lookup.

## Setup

- Add `https://ignav.com/mcp` as a remote MCP server; see https://ignav.com/docs/mcp.
