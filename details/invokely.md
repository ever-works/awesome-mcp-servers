# Invokely

Hosted MCP server for official statistics by indicator, place and period, with time series, comparisons, rankings and source citations for U.S., EU, Spanish and World Bank data.

## Basic Info

- **Name:** Invokely
- **Category:** Data Analysis & Exploration MCP Servers
- **Source URL:** https://invokely.ai/docs/
- **MCP Endpoint:** `https://invokely.ai/mcp`
- **Tags:** `statistics`, `open-data`, `oauth`, `remote`

## Features

- Query official statistics by indicator, place and period.
- Time series, comparisons and rankings.
- Coverage: U.S. states and counties, EU countries and regions, Spanish municipalities, and World Bank country and world data.
- Responses include source citations.

## Setup

- Connect to `https://invokely.ai/mcp` with OAuth or an API key.
- Trial endpoint without sign-up: `https://invokely.ai/mcp/trial` (25 calls per day per IP).
