# IPO Radar MCP

Free hosted MCP server with live Indian IPO data: grey market premium (GMP), subscription status, upcoming IPOs and GMP accuracy.

## Basic Info

- **Name:** IPO Radar MCP
- **Category:** Finance Market Data MCP Servers
- **Source URL:** https://github.com/songiangvan40006-boop/ipo-radar-mcp
- **MCP Endpoint:** `https://ipogmpradar.com/mcp`
- **Tags:** `india`, `stocks`, `market-data`, `remote`

## Features

- Live grey market premium (GMP) for Indian IPOs.
- Subscription status and upcoming IPOs.
- Historical GMP accuracy.

## Setup

- Claude (claude.ai / Claude Desktop): Settings, Connectors, add a custom connector with `https://ipogmpradar.com/mcp`.
- Any other MCP client: add the same URL as a remote server (Streamable HTTP). Free, no API key.
