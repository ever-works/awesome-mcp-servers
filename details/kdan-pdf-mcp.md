## Overview

KDAN PDF MCP is a free, unlimited remote MCP server that lets users organize, protect, compare, and redact PDFs using natural-language instructions in Claude or ChatGPT — no account required.

## Features

- Compress and reduce PDF file size
- Delete pages
- True redaction of sensitive information (PII)
- Compare two document versions side by side
- Add, change, or remove password protection
- Generate a download link for the finished file
