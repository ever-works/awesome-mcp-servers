# Lightning Wallet MCP

MCP server that gives AI agents a Bitcoin Lightning wallet with L402 support for autonomous micropayments to APIs and other agents.

## Basic Info

- **Name:** Lightning Wallet MCP
- **Category:** Blockchain Crypto Mcp Servers
- **Brand:** Lightning Faucet
- **Source URL:** https://github.com/lightningfaucet/lightning-wallet-mcp
- **MCP Endpoint:** `https://lightningfaucet.com/mcp`
- **Website:** https://lightningfaucet.com/ai-agents/
- **Tags:** `bitcoin`, `lightning-network`, `payments`, `l402`

## Features

- Bitcoin wallet for AI agents with Lightning Network payments.
- L402 support for paying for API access automatically.
- Machine-to-machine micropayments.

## Setup

- Local: `claude mcp add lightning-wallet -- npx -y lightning-wallet-mcp`
- Remote: `claude mcp add --transport http lightning-wallet https://lightningfaucet.com/mcp`
