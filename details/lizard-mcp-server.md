# Lizard MCP Server

Official MCP server for Lizard, an AI-native deployment platform: create services, add managed Postgres, Redis and S3, stream logs and metrics, set secrets, scale replicas and attach domains.

## Basic Info

- **Name:** Lizard MCP Server
- **Category:** Cloud & DevOps MCP Servers
- **Brand:** Lizard
- **Source URL:** https://github.com/lizard-build/lizard-mcp
- **MCP Endpoint:** `https://lizard.build/mcp`
- **Tags:** `deployment`, `cloud`, `oauth`, `official`

## Features

- 33 tools for deploying and running apps on Lizard.
- Create services and add managed Postgres, Redis and S3.
- Stream logs and metrics, set secrets, scale replicas and attach domains.
- Destructive actions need explicit confirmation.

## Setup

- Claude Code: `claude mcp add --transport http lizard https://lizard.build/mcp`
- Sign in with OAuth 2.1.
