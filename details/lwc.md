## Overview

LWC is a local-first, source-grounded project memory CLI for coding agents. Its stdio MCP server exposes one bounded, read-only exploration tool.

## Features

- Persistent Markdown and SQLite memory with FTS5 search
- Source citations, provenance, and atomic changesets
- Optional document and code graphs
- Supports Codex, Claude Code, Cursor, OpenCode, Gemini CLI, and other MCP clients

## Installation

```bash
npm install --global @i-xor/lwc
lwc serve --mcp
```
