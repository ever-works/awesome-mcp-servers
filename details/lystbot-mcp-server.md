# LystBot MCP Server

MCP server for the LystBot list app that gives AI agents control over grocery lists, to-dos and packing lists shared with family and friends.

## Basic Info

- **Name:** LystBot MCP Server
- **Category:** Project Management MCP Servers
- **Source URL:** https://github.com/TourAround/LystBot
- **Website:** https://lystbot.com
- **Tags:** `task-management`, `productivity`, `todo-list`

## Features

- 10 tools for creating, managing, checking off and sharing lists.
- Grocery lists, to-dos and packing lists shared with family and friends.
- Free iOS and Android app; also usable from a CLI (`npx lystbot`).
