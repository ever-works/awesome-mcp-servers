# Marketplace Search MCP

MCP server for searching 20+ online marketplaces such as OfferUp, Reverb, TCGPlayer, Craigslist and Poshmark, plus contractor and nurse license checks, PSA card data and NYC building violations.

## Basic Info

- **Name:** Marketplace Search MCP
- **Category:** Search Discovery MCP Servers
- **Source URL:** https://github.com/lulzasaur9192/marketplace-search-mcp
- **Tags:** `marketplace`, `search`, `e-commerce`

## Features

- One server with 19 tools for marketplace search and price data.
- Marketplaces include OfferUp, Reverb, TCGPlayer, Thumbtack, Craigslist and Poshmark.
- Contractor and nurse license verification, PSA grading data and NYC building violations.

## Setup

- Run with `npx @lulzasaur9192/marketplace-search-mcp`.
