# McClipFace

Remote MCP server that finds current coupon codes, promo codes, deals and discounts for stores and products; no authentication.

## Basic Info

- **Name:** McClipFace
- **Category:** Business Commerce MCP Servers
- **Source URL:** https://mcclipface.com
- **MCP Endpoint:** `https://mcclipface.com/mcp/read`
- **Tags:** `shopping`, `e-commerce`, `remote`

## Features

- Find current coupon and promo codes for a store.
- Look up deals and discounts for specific products.

## Setup

- Add `https://mcclipface.com/mcp/read` as a remote MCP server (Streamable HTTP). No authentication is required.
