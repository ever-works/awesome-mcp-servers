# mcp-chaos-rig

Local MCP server that breaks on demand so you can test MCP clients against auth failures, disappearing tools, flaky responses and token expiry, configured from a web UI.

## Basic Info

- **Name:** mcp-chaos-rig
- **Category:** Testing Debugging Tools
- **Source URL:** https://github.com/Typewise/mcp-chaos-rig
- **Tags:** `testing`, `chaos-engineering`, `mcp`

## Features

- Simulate auth failures and token expiry.
- Make tools disappear and responses flaky on demand.
- Configure every failure mode from a web UI.

## Setup

- Run with `npx mcp-chaos-rig`.
