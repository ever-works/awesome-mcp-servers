# newsmcp

Real-time world news for AI agents: events clustered from hundreds of sources, classified by 12 topics and 30+ regions and ranked by importance; free, no API key.

## Basic Info

- **Name:** newsmcp
- **Category:** News
- **Source URL:** https://github.com/pranciskus/newsmcp
- **Website:** https://newsmcp.io
- **Tags:** `news`, `search`, `api`

## Features

- World news events clustered from hundreds of sources.
- Classified by 12 topics and 30+ geographic regions, ranked by importance.
- Free, no API key required.

## Setup

- Claude Code: `claude mcp add newsmcp -- npx -y @newsmcp/server`
