# No Stairs Please MCP

Remote MCP server for finding independent live-music venues in the US and British Columbia, with booking contacts, capacity filters and tour routing.

## Basic Info

- **Name:** No Stairs Please MCP
- **Category:** Sports & Entertainment
- **Source URL:** https://nostairsplease.com/mcp
- **MCP Endpoint:** `https://nostairsplease.com/mcp`
- **Venue Directory:** https://nostairsplease.com/venues
- **Tags:** `music`, `geospatial`, `oauth`, `remote`

## Features

- Discover independent live-music venues in the US and British Columbia.
- Look up booking contacts for each venue.
- Filter venues by capacity.
- Plan tour routes between venues.

## Setup

- Add `https://nostairsplease.com/mcp` as a remote MCP server (Streamable HTTP) in any MCP client.
- The public venue directory is at https://nostairsplease.com/venues.
