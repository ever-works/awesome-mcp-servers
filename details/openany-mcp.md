## Overview

OpenAny is the B2A (business to agent) marketplace. One MCP endpoint gives agents 3,200+ APIs and 168+ AI models.

## Features

- Remote Streamable HTTP at https://mcp.openany.si
- 3,200+ APIs across social, SEO, crypto, company, finance, and legal
- 168+ AI models including GPT, Claude, Gemini, DeepSeek, Qwen, Midjourney, Veo, and Kling
- Browsing, search, and price checks are free; only run_api needs an API key

## Pricing

Pay per call. No subscription. MIT licensed.
