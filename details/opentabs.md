# OpenTabs

Plugin-based MCP server and Chrome extension that gives AI agents access to web apps through your logged-in browser session, with 100+ plugins and no API keys.

## Basic Info

- **Name:** OpenTabs
- **Category:** Browser Automation
- **Source URL:** https://github.com/opentabs-dev/opentabs
- **Website:** https://opentabs.dev
- **Tags:** `browser-automation`, `chrome-extension`, `plugins`

## Features

- Chrome extension plus MCP server: agents call web apps through your authenticated browser session.
- 100+ plugins for Slack, Discord, GitHub, Reddit, Todoist and more.
- No API keys required; a CLI mode is available for non-MCP use.
