# RemixViral

Cuts a long video you own into ranked, vertical, captioned Shorts. Its MCP server checks clip jobs, videos and credits and can create faceless Shorts from a prompt.

## Basic Info

- **Name:** RemixViral
- **Category:** Media Processing MCP Servers
- **Source URL:** https://remixviral.ai
- **MCP Endpoint:** `https://remixviral.ai/api/mcp`
- **Tags:** `video-editing`, `video-generation`, `creator-tools`, `remote`, `oauth`

## Features

- Hosted remote MCP endpoint `https://remixviral.ai/api/mcp`; OAuth or API key. Creating faceless Shorts spends account credits; clips of a long video are started in the app by uploading a file you own.
- Registry name `ai.remixviral/clipper`; npm package `@remixviral/mcp-server` 2.0.0.
- First clip project free with Google sign-in, no card: one video you own, up to 10 minutes, up to 3 ranked clips. Then one-time credit packs from $2.99, no subscription.
- Disclosure: submitted by the RemixViral team.

## Setup

- Add `https://remixviral.ai/api/mcp` as a remote MCP server and sign in; see https://remixviral.ai.
