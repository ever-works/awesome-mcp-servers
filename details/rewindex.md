# rewindex

Auto-snapshots every file change locally so you can rewind AI agent sessions, audit code and inspect diffs from your AI chat via MCP or a built-in dashboard.

## Basic Info

- **Name:** rewindex
- **Category:** Version Control
- **Source URL:** https://github.com/crsxmd/rewindex
- **Website:** https://rewindex.org
- **Tags:** `version-control`, `developer-tools`, `ai-coding`

## Features

- Snapshots every file change locally, including changes you have not committed to Git.
- Rewind sessions, audit code and inspect diffs from your AI chat or the built-in dashboard.
- Works with any AI agent through MCP, alongside Git.

## Setup

- Install with `pip install rewindex`, then register it as an MCP server in your agent (per-agent steps are in the repository).
