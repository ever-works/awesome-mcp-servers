# RunComfy MCP

Official remote MCP server for RunComfy with 31 tools for ComfyUI serverless deployments, hosted model inference and LoRA training jobs.

## Basic Info

- **Name:** RunComfy MCP
- **Category:** Media Processing MCP Servers
- **Brand:** RunComfy
- **Source URL:** https://github.com/runcomfy-com/runcomfy-mcp
- **MCP Endpoint:** `https://mcp.runcomfy.com/mcp`
- **Website:** https://www.runcomfy.com
- **Tags:** `image-generation`, `video-generation`, `comfyui`, `official`

## Features

- Manage ComfyUI serverless deployments.
- Run hosted model inference for image and video generation.
- Start and monitor LoRA training jobs.

## Setup

- Claude Code: `claude mcp add --transport http runcomfy https://mcp.runcomfy.com/mcp --header "Authorization: [redacted secret]"`
- Docs: https://docs.runcomfy.com/mcp
