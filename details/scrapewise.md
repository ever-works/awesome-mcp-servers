# Scrapewise

Remote MCP server that scrapes, cleans and matches product and price data from any website into AI-ready records.

## Basic Info

- **Name:** Scrapewise
- **Category:** Web Scraping
- **Source URL:** https://github.com/BEBOTECH-OU/scrapewise-mcp
- **MCP Endpoint:** `https://mcp.scrapewise.ai/mcp`
- **Website:** https://scrapewise.ai/mcp
- **Tags:** `web-scraping`, `data-extraction`, `e-commerce`, `remote`

## Features

- Scrape product and price data from any website.
- Clean and normalise the extracted data.
- Match the same product across different sites.

## Setup

- Claude Code: `claude mcp add scrapewise --transport http https://mcp.scrapewise.ai/mcp`
- Other clients: add `https://mcp.scrapewise.ai/mcp` as a remote (Streamable HTTP) MCP server.
- The connection kit is MIT-licensed on GitHub.
