## Overview

Screenpipe captures screen text and audio history locally and makes that history searchable by AI assistants through its official MCP server.

- [MCP server and setup documentation](https://github.com/screenpipe/screenpipe/tree/main/packages/screenpipe-mcp)
- [Product website](https://screenpipe.com/)

## Features

- Search captured screen text and audio transcriptions for work recall and meeting context.
- Connect MCP-compatible AI clients to a running Screenpipe instance using the documented local API authentication setup.
- Keep raw history local by default. Configured cloud AI, transcription, sync, and integrations can transmit context off-device.
