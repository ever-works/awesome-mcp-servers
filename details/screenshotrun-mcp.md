# ScreenshotRun MCP

MCP server for the ScreenshotRun API: capture web pages, render HTML or Markdown to images and extract page metadata, with device emulation, dark mode and full-page capture.

## Basic Info

- **Name:** ScreenshotRun MCP
- **Category:** Media Processing MCP Servers
- **Source URL:** https://github.com/screenshotrun/screenshotrun-mcp
- **Website:** https://screenshotrun.com
- **Tags:** `screenshot`, `api`, `browser-automation`

## Features

- Capture screenshots of any web page, including full-page captures.
- Render HTML or Markdown to an image.
- Extract page metadata.
- Device emulation, dark mode, ad blocking and stealth mode.

## Setup

- Run with `npx -y screenshotrun-mcp` and a ScreenshotRun API key (see the repository README for client configuration).
