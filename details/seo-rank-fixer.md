# SEO Rank Fixer

Hosted MCP server that reads your Google Search Console and Bing data and returns SEO fixes ranked by the clicks they can win, plus site audits, index status and AI search visibility.

## Basic Info

- **Name:** SEO Rank Fixer
- **Category:** SEO
- **Source URL:** https://seorankfixer.com/connectors
- **MCP Endpoint:** `https://seorankfixer.com/api/mcp`
- **Tags:** `seo`, `analytics`, `oauth`, `remote`

## Features

- Reads Google Search Console and Bing Webmaster data for your sites.
- Returns SEO fixes ranked by the clicks they can win.
- Site audits, index status and page scans.
- AI search visibility checks.

## Setup

- Add `https://seorankfixer.com/api/mcp` as a remote MCP server (Streamable HTTP).
- Sign in with OAuth 2.1; connect Search Console and Bing in your SEO Rank Fixer account.
