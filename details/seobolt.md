# SEOBolt

Technical SEO and AI-search audit with a code-level fix plan your coding agent can apply over MCP: crawl, prioritised fixes with code snippets, then re-crawl to verify.

## Basic Info

- **Name:** SEOBolt
- **Category:** SEO
- **Source URL:** https://seobolt.app/mcp-seo
- **MCP Endpoint:** `https://seobolt.app/mcp`
- **Tags:** `seo`, `ai-search`, `remote`, `oauth`, `api-key`

## Features

- Hosted remote MCP endpoint `https://seobolt.app/mcp` with 27 tools; OAuth or API key.
- Registry name `app.seobolt/seobolt`; npm package `mcp-server-seobolt` 1.1.0.
- No proprietary backlink or keyword index and no live rank checker; tools that need that data say so.
- Pricing: no free plan for the MCP server. A free audit needs no sign-up on the site; paid access starts with a $2.99 non-refundable 3-day trial, then from $19/month.
- Disclosure: submitted by the SEOBolt team.

## Setup

- Add `https://seobolt.app/mcp` as a remote MCP server and sign in; see https://seobolt.app/mcp-seo.
