# SettleGrid Discovery

MCP discovery server from SettleGrid, a per-call billing and settlement layer for AI tools, that lets agents search monetized tools by category and see their pricing.

## Basic Info

- **Name:** SettleGrid Discovery
- **Category:** Finance & Fintech
- **Source URL:** https://github.com/lexwhiting/settlegrid
- **Website:** https://settlegrid.ai
- **npm:** https://www.npmjs.com/package/@settlegrid/discovery
- **Tags:** `payments`, `billing`, `discovery`

## Features

- Agents discover monetized tools, search by category and get pricing through MCP.
- Part of SettleGrid, a settlement layer for AI agent payments with per-call billing across several payment protocols.

## Setup

- Run the discovery server with `npx @settlegrid/discovery`.
