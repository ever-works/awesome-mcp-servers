MCP server for crypto market intelligence: funding rates, futures and options data, arbitrage, narratives, exchange listings and news.

## Overview

Sharpe MCP Server exposes crypto market intelligence through the Model Context Protocol, including funding rates, futures and options data, arbitrage opportunities, narratives, exchange listings, and news. It is designed for MCP-compatible agents that need market context for crypto research and trading workflows.
