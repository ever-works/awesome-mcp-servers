# Signbee MCP Server

Official Signb.ee MCP server that lets AI agents send Markdown or PDF documents for two-party e-signing with SHA-256 audit trails, OTP verification and webhooks.

## Basic Info

- **Name:** Signbee MCP Server
- **Category:** Document Management MCP Servers
- **Brand:** Signbee
- **Source URL:** https://github.com/signbee/mcp
- **Website:** https://signb.ee
- **Tags:** `e-signature`, `pdf`, `legal`, `webhooks`

## Features

- Send a Markdown or PDF document for legally binding two-party e-signing in one tool call.
- SHA-256 certified delivery and audit trail.
- OTP verification of signers.
- Webhook notifications on signing events.
