# SLM MCP Hub

Local-first MCP gateway that federates stdio and HTTP MCP servers behind one endpoint, with background startup, retries and cost tracking.

## Basic Info

- **Name:** SLM MCP Hub
- **Category:** Mcp Middleware Orchestration
- **Source URL:** https://github.com/qualixar/slm-mcp-hub
- **Tags:** `mcp-gateway`, `gateway`, `python`

## Features

- Federates many MCP servers (stdio and HTTP) behind a single endpoint.
- Background startup, auto-retry with exponential backoff, and cost tracking.
- Python and Node implementations.

## Setup

- Install with `pip install slm-mcp-hub` (optional extras: `network`, `observability`, `full`).
