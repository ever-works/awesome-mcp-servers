snapapi-mcp-server provides MCP integration for the SnapAPI web data extraction service. It gives AI assistants the ability to capture website screenshots, extract Open Graph and Twitter Card metadata, generate PDFs from URLs, and pull clean text content from webpages. Connects to the SnapAPI REST service which offers a free tier (50 requests/month) and paid plans starting at $5/month.
