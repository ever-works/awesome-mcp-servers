# Social media studio

Hosted MCP server for drafting, scheduling, and publishing social posts, managing connected accounts and media, and reading post analytics.

[Social media studio](https://so-me.studio)

- Endpoint: `https://api.so-me.studio/mcp/directory`
- Transport: Streamable HTTP
- Authentication: OAuth
- Access: Requires a paid Social media studio plan with MCP access and connected social accounts.
- [Setup documentation](https://docs.so-me.studio/mcp/overview)
