# SpeedOf.Me MCP

Official SpeedOf.Me MCP server for internet speed tests (download, upload, latency, jitter) from AI agents, also usable as a CLI and SDK.

## Basic Info

- **Name:** SpeedOf.Me MCP
- **Category:** Monitoring
- **Brand:** SpeedOf.Me
- **Source URL:** https://github.com/SpeedOfMe/speedofme-mcp
- **npm:** https://www.npmjs.com/package/@speedofme/mcp
- **Website:** https://speedof.me/api
- **Tags:** `network`, `monitoring`, `official`

## Features

- Internet speed tests: download, upload, latency and jitter.
- Uses SpeedOf.Me's global Fastly edge test servers.
- Local history of past tests; also works as a CLI and SDK.

## Setup

- Install the `@speedofme/mcp` npm package and add it to your MCP client.
