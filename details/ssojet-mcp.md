# SSOJet MCP

SSOJet is an OAuth 2.1 authorization server for MCP servers and enterprise apps, with enterprise SSO (SAML/OIDC), PKCE, scoped tokens, consent flows and dynamic client registration.

## Basic Info

- **Name:** SSOJet MCP
- **Category:** Authentication
- **Brand:** SSOJet
- **Source URL:** https://ssojet.com/docs/en/ai-identity/mcp-remote-server
- **Tags:** `authentication`, `oauth`, `sso`, `security`

## Features

- OAuth 2.1 authorization server for remote MCP servers.
- Enterprise SSO through SAML and OIDC federation.
- PKCE, scoped tokens and consent flows.
- Dynamic client registration (DCR) for MCP clients.

## Setup

- The SSOJet guide walks through cloning an MCP server, creating an SSOJet application and protecting the server with SSOJet auth.
