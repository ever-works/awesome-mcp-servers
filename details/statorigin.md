# StatOrigin

Hosted, read-only MCP server for searching an open archive of industry statistics, each with its publisher, source document URL and the sentence the figure came from.

## Basic Info

- **Name:** StatOrigin
- **Category:** Data Analysis & Exploration MCP Servers
- **Source URL:** https://statorigin.org/docs/mcp
- **MCP Endpoint:** `https://statorigin.org/mcp`
- **Tags:** `statistics`, `open-data`, `research`, `remote`

## Features

- `search`: find statistics in the open archive.
- `fetch`: read a statistic with its publisher, source document URL and the quoted sentence it came from.
- `get_ranking`: ranked lists of figures.

## Setup

- Add `https://statorigin.org/mcp` as a remote MCP server (Streamable HTTP). No authentication.
