# Strale

MCP server for Strale's data capability catalog: company registry lookups in 27 countries, sanctions and PEP screening, IBAN, VAT and LEI validation, web intelligence and document extraction.

## Basic Info

- **Name:** Strale
- **Category:** Business Commerce MCP Servers
- **Source URL:** https://strale.io
- **MCP Endpoint:** `https://api.strale.io/mcp`
- **Tags:** `compliance`, `validation`, `company-data`

## Features

- Company registry lookups across 27 countries.
- Sanctions and PEP screening.
- IBAN, VAT and LEI validation.
- Web intelligence and document extraction.
- Five capabilities are free without authentication.

## Setup

- Add `https://api.strale.io/mcp` as a remote MCP server (Streamable HTTP).
