## Features

- **US & global equities:** stock price, OHLCV, fundamentals, analyst ratings, earnings surprises, dividends, insider trades, SEC filings, options chain, short volume intel
- **Crypto & DeFi:** price feeds, DEX swap quotes, trending pools, DeFi yields, wallet screening, token security scoring, on-chain whale radar, mempool intel
- **Macro & alternatives:** treasury yields, FOMC tracker, economic calendar, commodities, forex rates, housing brief, labor market data
- **Compliance & KYB:** OFAC sanctions screening (19K+ SDN entries, F1 fuzzy matching), NPI provider lookup, FEC donor search, congressional trades tracker
- **Research & web:** news sentiment, Reddit intel, GitHub repo analysis, fact-check, research paper synthesis, web scraping, page intel

## Use Cases

- Autonomous AI agents needing real-time market data without managing API keys
- Agent-to-agent commerce scenarios (x402 payment protocol)
- Multi-modal research agents combining financial, compliance, and web data

## Pricing

Pay-per-call via x402 (USDC on Base): $0.001–$1.50 per call. No subscription. No API key.
