# Unfetch

Unfetch is a hosted Google Ads MCP server that connects AI assistants to marketing data for campaign analysis, SEO reporting, and keyword research.

## Features

- Google Ads campaign, keyword, search-term, spend, budget, and conversion reporting.
- Google Analytics traffic and conversion reporting.
- Google Search Console query and landing-page reporting.
- Keyword research with search demand, competition, CPC, and bid estimates.
- Public web and landing-page research, plus follow-up analysis across report results.
- Multiple brands, with access following the user's Unfetch membership and brand assignments.

MCP reporting is read-only for connected advertising and analytics accounts. It cannot change campaigns, bids, budgets, or analytics properties.

## Connection

Create a free Unfetch account and connect the data sources for the brand you want to analyze. Add the remote MCP endpoint in a compatible client and complete OAuth authorization.

- **Endpoint:** https://unfetch.com/api/mcp
- **Transport:** Streamable HTTP
- **Authentication:** OAuth
- **Website:** https://unfetch.com
- **Setup instructions:** https://unfetch.com/plugin
- **Public plugin and client configuration:** https://github.com/unfetch-com/agent-plugin
- **Pricing and plan limits:** https://unfetch.com/pricing

The service is hosted by Unfetch. The public repository contains installation instructions, reporting guidance, and client configuration.
