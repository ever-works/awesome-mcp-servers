## Features

- Local-first storage in SQLite, user-owned by default
- Written in Rust, distributed as a single binary
- FSRS-6 retention scheduling
- Prediction-error gating on writes
- Active forgetting and spreading activation
- Hybrid retrieval across exact and semantic lookup
- Provenance and correction tools
- 3D dashboard embedded in the release binary
- Works with Claude Code, Cursor, VS Code, Codex, Windsurf, and JetBrains
