# VideoOverlayKit

Free, MIT-licensed local MCP server that drives Remotion to render short animated b-roll overlay videos from a script, for short-form and landscape video.

## Basic Info

- **Name:** VideoOverlayKit
- **Category:** Media Processing MCP Servers
- **Source URL:** https://github.com/alichherawalla/video-overlay-kit
- **Website:** https://alichherawalla.github.io/video-overlay-kit/
- **Tags:** `video`, `video-generation`, `local`

## Features

- Render 4-6 second animated b-roll overlays for LinkedIn, Instagram Reels, YouTube Shorts, TikTok and landscape video.
- Paste a script: the agent writes the scene spec and renders an MP4.
- Runs locally and drives Remotion.
