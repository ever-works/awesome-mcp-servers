# VideoGen MCP

Official VideoGen server for creating and editing videos, images, voiceovers, music, and avatars from MCP clients.

- Website: https://videogen.io/videogen-mcp
- Source: https://github.com/video-gen/videogen-mcp
- Documentation: https://docs.videogen.io/libraries/mcp
- Tool schemas: https://github.com/video-gen/videogen-mcp/blob/main/TOOL_SCHEMAS.md
- License: MIT

## Connect

Hosted Streamable HTTP endpoint: `https://mcp.videogen.io/mcp`. Authenticate with OAuth 2.1 or your VideoGen API key.

For local stdio, run `npx -y @videogen/mcp` with Node.js 20+ and the `VIDEOGEN_API_KEY` environment variable. Your VideoGen account needs credits for generation.

## Capabilities

Create videos from scripts, voiceovers, slideshows, or storyboards; generate images, video clips, voiceovers, music, and avatars; upload media; inspect workflow progress; edit projects and export videos.
