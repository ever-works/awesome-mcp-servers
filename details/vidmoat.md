# Vidmoat

Hosted AI video editor with a remote MCP server: agents import footage, edit a real multi-track timeline, preview frames and render MP4s.

## Basic Info

- **Name:** Vidmoat
- **Category:** Media Processing MCP Servers
- **Source URL:** https://developer.vidmoat.com/developer/docs/build
- **MCP Endpoint:** `https://api.vidmoat.com/api/mcp`
- **Tags:** `video`, `video-editing`, `remote`

Vidmoat is a hosted AI video editor. Its remote MCP server lets MCP clients such as Claude and Cursor create projects, import media, edit a multi-track timeline, preview rendered frames, transcribe and render finished MP4s. The same projects can also be edited in the web editor and on Telegram.

- **Endpoint:** `https://api.vidmoat.com/api/mcp`
- **Transport:** Streamable HTTP (remote, nothing to install)
- **Authentication:** OAuth, or a Bearer API key from the Vidmoat dashboard
- **Pricing:** Test keys are free on every plan; live MCP and API access need the Studio plan
- **Official MCP Registry name:** `com.vidmoat/vidmoat`
- **Documentation:** [Vidmoat developer docs](https://developer.vidmoat.com/developer/docs/build)
