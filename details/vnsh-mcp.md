# vnsh-mcp

MCP server for vnsh, an encrypted, ephemeral shared workspace for AI agents: client-side AES-256 encryption and content that disappears 24 hours after the last edit.

## Basic Info

- **Name:** vnsh-mcp
- **Category:** File Management MCP Servers
- **Source URL:** https://github.com/raullenchai/vnsh
- **Website:** https://vnsh.dev
- **Tags:** `file-sharing`, `encryption`

## Features

- Read vnsh URLs and share large outputs between agents.
- Client-side AES-256 encryption.
- Content disappears 24 hours after the last edit.

## Setup

- Claude Code: `claude mcp add vnsh -- npx -y vnsh-mcp`
