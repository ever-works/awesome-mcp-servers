# WatchCron MCP

MCP server for WatchCron cron-job and uptime monitoring: create monitors with intervals or cron expressions, view ping history, manage incidents and pause or resume monitors.

## Basic Info

- **Name:** WatchCron MCP
- **Category:** Monitoring
- **Source URL:** https://github.com/watchcron/watchcron-mcp
- **Website:** https://watchcron.com
- **Tags:** `monitoring`, `cron-jobs`, `alerts`

## Features

- Create monitors with fixed intervals or cron expressions.
- View ping history and manage incidents.
- Pause and resume monitors.
- List notification channels.

## Setup

- Run with `npx -y watchcron-mcp` and a WatchCron API key (see the repository README for client configuration).
