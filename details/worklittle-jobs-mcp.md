# Worklittle Jobs MCP

Open-source remote MCP server for job search: search over 4 million jobs with visa, salary and distance filters, swipe to apply from your AI app, and save roles to a Worklittle account.

## Basic Info

- **Name:** Worklittle Jobs MCP
- **Source URL:** https://github.com/worklittle/jobs-mcp
- **MCP Endpoint:** `https://mcp.worklittle.com/` (Streamable HTTP)
- **Docs:** https://docs.worklittle.com/mcp
- **MCP Registry:** `io.github.worklittle/jobs`
- **License:** MIT

## Features

- Search 4 million+ job listings.
- Filter by visa sponsorship, salary and distance.
- Apply to roles and save them to a Worklittle account from inside an AI app.

## Setup & Configuration

- Add `https://mcp.worklittle.com/` as a remote MCP server in an MCP-compatible client.
- See https://docs.worklittle.com/mcp for client-specific steps.
