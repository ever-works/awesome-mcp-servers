# x402engine-mcp

MCP server that connects agents to 100+ x402 pay-per-call APIs (LLMs, image and video, web, code, crypto, audio, travel and IPFS) with budgeted USDC payments.

## Basic Info

- **Name:** x402engine-mcp
- **Category:** Blockchain Crypto Mcp Servers
- **Source URL:** https://github.com/agentc22/x402engine-mcp
- **Website:** https://x402engine.app
- **Tags:** `x402`, `payments`, `ai-agents`, `usdc`

## Features

- Discover live x402 pay-per-call APIs, including 70+ LLMs plus image and video, web, code, crypto, audio, travel and IPFS services.
- Pay per call with USDC on Base or Solana, or USDm on MegaETH, within a set budget.

## Setup

- Claude Code: `claude mcp add x402engine -- npx -y x402engine-mcp`
