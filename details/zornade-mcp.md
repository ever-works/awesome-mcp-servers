## Overview

Zornade MCP exposes Italian cadastral, geospatial and real-estate data to AI
assistants over the Model Context Protocol. Six tools cover geocoding on 18.7M+
addresses, reverse geocoding, cadastral parcel profiles (risk, solar potential,
valuations, POI), parcel lookup by point or bounding box, parcel search and
administrative lists, for all 85M+ italian parcels.

## Features

- Geocoding and reverse geocoding on the full Italian address base (ANNCSU)
- Parcel profiles with risk layers, solar potential and valuations
- Parcel lookup by point, list of points or bounding box
- Administrative lists (regions, provinces, municipalities)
- Hosted endpoint, no installation required

## Getting Started

1. Get a free API key at https://app.zornade.com/api (10,000 requests/hour)
2. Add the server to any MCP client: https://mcp.zornade.com/mcp
3. Or self-host via Docker (see the repository)
